## 2. გამოიყენეთ სხავადასხვა ხელსაწოები თავსებადობის ტესტირებისთვის

## 3. იპოვეთ თავსებადობის ხარვეზები და უზრუნველყავით მათი აღმოფხვრა

## სურათები

ცვლილებების დაწყებამდე გახსენი გვერდი DevTools-ის მოწყობილობის რეჟიმში. **360px** და **1280px** სიგანეზე ცალ-ცალკე გადაიღე ეკრანის სურათები.

ხარვეზების გამოსწორების შემდეგ ორივე ზომაზე ხელახლა გადაიღე სურათები, იმავე პარამეტრებით.

სურათებში ჩანდეს გვერდიც და DevTools-ის ის ნაწილი, სადაც ეკრანის ზომაა მითითებული.

გადაამოწმე შესწორებული გვერდი კიდევ რამოდენიმე ბრაუზერში და გადაიღე ფოტოები,

სურათები შეინახე ამ დავალების საქაღალდეში შექმნილ `screenshots/` საქაღალდეში. ფაილის სახელში მიუთითე ბრაუზერი, სიგანე და ეტაპი, მაგალითად: `chrome-360-before.png` და `chrome-360-after.png`.

## რა უნდა გააკეთო

1. HTML-ში დაამატე `viewport` მეტატეგი, რომ გვერდი მოწყობილობის ეკრანის სიგანეს მოერგოს.
2. შეცვალე გვერდის ფიქსირებული სიგანე ისე, რომ შინაარსი პატარა ეკრანზეც დაეტიოს.
3. სამი ბარათი განალაგე მოქნილად: ვიწრო ეკრანზე ისი ახალ ხაზზე ან ერთმანეთის უნდა გადადიოდნენ.
4. გამოასწორე ბარათების ტექსტის ფიქსირებული სიმაღლით გამოწვეული ხარვეზები.

გამოიყენე Flexbox ან Grid. საჭიროების შემთხვევაში დაამატე მარტივი media query.
