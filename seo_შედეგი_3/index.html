ღია გაკვეთილები დამწყებთათვის

გაკვეთილებზე გაეცნობი ვებგვერდის აწყობის საფუძვლებს და შეასრულებ მცირე პრაქტიკულ დავალებებს.

რას ვისწავლით

HTML გვერდის სტრუქტურა

ვისწავლით სათაურების, აბზაცებისა და ბმულების დამატებას. გაკვეთილის ბოლოს ამ ელემენტებით მარტივ გვერდს ავაწყობთ.

CSS გვერდის გაფორმება

შევცვლით ტექსტის ფერსა და ზომას, ელემენტებს შორის დაშორებას. შემდეგ გვერდს ტელეფონის ეკრანსაც მოვარგებთ.

JavaScript ღილაკები

გვერდს ღილაკს დავუმატებთ და დაჭერისას დამატებით ტექსტს გამოვაჩენთ. განმეორებით დაჭერისას ტექსტი დაიმალება.

შეხვედრის დეტალები

შეხვედრა უფასოა და 45 წუთს გრძელდება.

გაკვეთილზე დასწრება წინასწარ ცოდნას არ მოითხოვს.
