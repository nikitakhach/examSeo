საიტების დამზადება

კურსზე ვისწავლით HTML-ს, CSS-სა და JavaScript-ს. გაკვეთილზე მცირე დავალებას შევასრულებთ.

რას ვისწავლით

  • HTML

    გვერდზე დავამატებთ სათაურებს, ტექსტს, ბმულებსა და სურათებს.

  • CSS

    გვერდს გავაფორმებთ და სხვადასხვა ზომის ეკრანს მოვარგებთ.

  • JavaScript

    ღილაკზე დაჭერისას გვერდზე დამატებით ინფორმაციას გამოვაჩენთ.

სურათთან მუშაობა
